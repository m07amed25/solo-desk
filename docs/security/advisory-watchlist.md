# Dated upstream advisory watchlist

Reviewed 29 October 2026 against the first visible pages of the [Next.js maintainer index](https://github.com/vercel/next.js/security/advisories) and [Better Auth maintainer index](https://github.com/better-auth/better-auth/security/advisories). This is a **partial discovery snapshot**, not every advisory/page/CVE, a complete version match, or a list of confirmed SoloDesk vulnerabilities. Additional pages, bundled/transitive packages and other component feeds still need review.

GHSA is a valid advisory identifier even when a CVE alias has not been verified here. Follow each primary source for its full current affected/fixed ranges, prerequisites, updates and recovery instructions. The simplified ranges below are dated observations, not permanent minimum-safe versions; later advisories can affect a release that fixes an older issue.
