# Website design direction

Updated 29 October 2026. Design-stage contract, not implemented website functionality. Mode: Operate.

SoloDesk helps freelance software engineers and small teams plan delivery, capture/review time, invoice clients and review collections. Each screen makes the current workspace, next permitted action and reliability of data clear. Preserve the inherited spacious productivity direction and supplied graphite/silver logo, using Linear, Notion and GitHub as quality references without copying branding.

shadcn/ui is the primary component foundation. Reusable primitives/composites, semantic Tailwind tokens, accessible interactions and scalability are primary requirements. Use one coherent system across internal workspace and client portal. Retain light/dark themes with System default, larger controls, readable rows and English/Arabic RTL.

On wide screens use sidebar, utilities, title/action, filters and a useful work collection; adapt sidebar/context to phone/tablet layouts. Preserve website links/history and browser chrome. Timer, workspace, honest browser-draft/server save state and permissions remain discoverable. Do not add native titlebar/tray controls or desktop minimum dimensions.

Neon and Better Auth underpin planned persistence/identity; no UI control grants authority. Server services enforce current resource/action grants and exact financial state. Offline drafts require reviewed browser key, quota/eviction and recovery proof. Uncertain timer/issuance outcomes stay explicit.

Fixtures include long Arabic/English names, mixed-direction identifiers, many rows, 0/2/3-decimal currencies, missing/stale data, denied finance, narrow layouts and lost replies.
