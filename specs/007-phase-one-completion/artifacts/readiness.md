## 3. Downstream Execution Rules

1. **Gate Preservation**: A blocked gate blocks all dependent tasks from claiming successful completion.
2. **Local vs Live Distinction**: Local unit/contract tests, schema definitions, and mocked harnesses can be implemented and run to establish code correctness without asserting live gate approval.
3. **Evidence Integrity**: All test runs, baseline recordings, and audit results must record exact commands, hashes, and observed errors.
